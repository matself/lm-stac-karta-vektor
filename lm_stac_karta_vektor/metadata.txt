about=Search and download open vector data directly from Lantmäteriet's (the Swedish
    mapping, cadastral and land registration authority) STAC-vektor service: Byggnader
    (buildings), Marktäcke (land cover), Fastighetsindelning (cadastral boundaries),
    Belägenhetsadresser (addresses), Ortnamn (place names) and Kommun/lan/rike
    (municipality/county/country), plus the open Topografisk webbkarta raster map
    (topowebb, STAC-karta), which is cut out for a chosen extent straight from the
    140-175 GB source files instead of downloaded whole. Independent plugin, not developed by Lantmäteriet.
    Sibling plugin to Geodata: Ortofoto & höjd (Lantmäteriet), which covers
    orthophoto and elevation data. Search works with any valid key; download requires a system
    account that has ordered the right product on Geotorget. Login goes through
    QGIS' own Authentication Manager (OAuth2 client credentials) - the plugin does
    not store any credentials itself. Covers Sweden only. The user interface is in
    Swedish; see the README for an English explanation of every dialog and message.
    Downloaded layers are styled with Lantmäteriet's own official QGIS symbology 
    where available (currently Fastighetsindelning and Marktäcke); a bundled font (LMTopografisymboler,
    downloaded from Lantmäteriet's own product documentation) is registered for
    the QGIS session only, never installed system-wide, see the README for
    details and license note.

Instead of downloading the 140-175 GB source files, the plugin cuts out the chosen extent as a GeoTIFF or GeoPackage at a selectable resolution, with the area outlined on the map canvas. Also a shorter dock, mouse-wheel protection for combo boxes and date fields, and a corrected default time filter.
    1.0.3: Added official Topo10 styling for downloaded Byggnader (building areas), including features with illustrative position.
